# 🎁 Ловець легальних роздач ігор (Windows)

Один застосунок (`.exe`), який стежить за **офіційними безкоштовними роздачами**
ігор через публічний API [GamerPower](https://www.gamerpower.com/) (Epic Games,
Steam, GOG, Prime Gaming тощо). Коли з'являється нова роздача:

- 🔔 показує **сповіщення Windows**,
- 📋 **копіює посилання на роздачу в буфер обміну** (Ctrl+V — і вставив),
- за бажанням відкриває сторінку в браузері.

Працює **фоном у треї** біля годинника і **запускається разом із Windows**.
Типово ловить роздачі **будь-яких ігор**. Нічого не зламує і не перебирає ключі —
лише офіційні безкоштовні роздачі, які ти забираєш сам за посиланням.

## Як отримати готовий .exe

1. Вкладка **Actions** угорі → зліва workflow **Build EXE**.
2. Відкрий останній зелений запуск → внизу блок **Artifacts** →
   завантаж **RE4-Giveaway-Catcher-exe** (прийде `.zip`).
3. Розпакуй `.zip` → усередині `RE4-Giveaway-Catcher.exe` → двічі клікни.
   Нічого встановлювати не треба.

> Windows SmartScreen може попередити, бо файл без підпису: **Докладніше → Все
> одно виконати**. Код відкритий — він у `tracker.py`.

## Налаштування

Поряд з `.exe` при першому запуску з'явиться `config.json`:

```json
{
  "keywords": [],
  "check_interval_minutes": 15,
  "types": ["game"],
  "copy_to_clipboard": true,
  "auto_open_browser": false,
  "autostart": true
}
```

- `keywords` — що ловити. `[]` = **всі** роздачі. Приклад: `["resident evil"]`.
- `check_interval_minutes` — як часто перевіряти.
- `types` — `game` (повні ігри/ключі), `loot`, `dlc`.
- `auto_open_browser` — `true`, щоб сам відкривав сторінку роздачі.
- `autostart` — запуск разом із Windows (можна вимкнути в меню трея).

Поряд також буде `log.txt` (журнал) і `seen.json` (щоб не сповіщати двічі).

## Меню в треї

Правий клік по іконці біля годинника:
- **Перевірити зараз** — не чекати інтервал.
- **Відкрити останню роздачу** — у браузері.
- **Відкрити папку** — де лог і налаштування.
- **Автозапуск з Windows** — увімкнути/вимкнути.
- **Вийти**.
